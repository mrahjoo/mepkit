# Raw Data Directory

This directory is intended for storing raw data files that will be used for creating charts, data tables, and calculators across the MEPKit platform.

You can place the following types of files here:
- `.csv` (Data exports)
- `.sql` (Database queries and schema designs)
- `.json` (Raw JSON payloads or configuration data)
- `.xlsx` or other raw spreadsheet data

**Note:** If these files contain sensitive information or are very large, you may want to add them to `.gitignore` so they are not committed to the repository. If they are small, reference data sets, they can be safely committed.
